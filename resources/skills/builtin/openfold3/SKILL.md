# OpenFold3 开源 AF3 复现

## 先分清两个东西

- **OpenFold**（无 3）是 AlphaFold2 的可训练复现。它的输出、置信度、陷阱与 `alphafold2`
  完全同构，差别只在实现与可训练性。
- **OpenFold3** 是 AlphaFold3 架构的开源复现：扩散式结构生成，原生支持蛋白、DNA、RNA、
  小分子、离子与修饰残基。

搞混的后果是找错文档、用错输入格式。要 AF2 语义就去 `alphafold2`，这里讲的是 OpenFold3。

## 它在这一代里的位置

`boltz-2`、`chai-1`、OpenFold3 都是共折叠模型。OpenFold3 的差异是**可训练**：架构与训练
代码都开放，因此它是唯一能在自己的数据上微调的那个。

这对研究的意义很具体：如果你的体系是模型训练分布里稀薄的部分（某类非天然骨架、特定的
核酸-蛋白复合物、带非标准修饰的体系），微调是唯一能真正提升精度的路径，而不是反复调
recycle。

代价：微调需要相当规模的算力与配对结构数据，不是一个下午能做完的事。多数场景下先用
现成权重推理，确认精度不够、且不够的原因是分布外，再考虑微调。

## 推理

输入是 JSON schema（实体列表 + 可选 MSA/模板路径）：

```json
{
  "name": "complex_1",
  "sequences": [
    { "protein": { "id": "A", "sequence": "MKVLWAALLVTFLAGCQAK..." } },
    { "dna":     { "id": "B", "sequence": "ACGTACGTACGT" } },
    { "ligand":  { "id": "L", "smiles": "CC(=O)Oc1ccccc1C(=O)O" } },
    { "ion":     { "id": "Z", "ccd": "MG" } }
  ]
}
```

```bash
python -m openfold3.inference \
  --input input.json \
  --output_dir out/ \
  --num_diffusion_samples 5 \
  --num_recycles 10 \
  --seed 42
```

同样的三条纪律，与 `boltz-2` / `chai-1` 一致，因为它们同属扩散一代：

1. **采样数至少 5**，单样本没有一致性判据
2. **固定并记录 seed**，扩散是随机的
3. **界面看链对分解的 ipTM**，不看全局标量

离子与辅因子用 `ccd` 三字母码（`MG`、`ZN`、`HEM`、`ATP`…）。这是 OpenFold3 相对 AF2 的
实质增益之一：金属位点的几何在有离子时才对得上，AF2 的 apo 预测在这类位点上系统性偏差。

## 两个必须在方法里交代的问题

### 权重许可

结构预测这一代模型的权重许可**各不相同**，而且与代码许可常常不是一回事。有的权重限
非商业用途，有的要求署名，有的对再分发有约束。

这件事必须在动手前查清并记录，因为它影响的不是技术而是**论文能不能发、成果能不能转化**。
具体做法：

- 记录你实际下载的那个权重文件的来源 URL 与许可条款版本
- 在 `data-availability-statement` 里写明用了哪个模型的哪个权重
- 商业用途或专利相关工作先确认条款

平台不替你判断许可。它只提醒你：这一步的结论如果建立在一个不能用于你的用途的权重上，
问题会在最不方便的时候暴露。

### 基准泄漏

与 `alphafold2` 同类的问题，但在这一代更隐蔽：训练集包含 PDB 到某个截止日期的全部结构，
**以及**配体复合物。拿一个截止日期之前的 holo 结构去评估共折叠能力不构成评估。

做评估时：

- 用截止日期之后存进 PDB 的结构
- 显式关掉模板
- 报告你用的截止日期与评估集的日期范围

不这么做的话，得到的高精度是记忆而不是泛化，而这个区别在方法学上是决定性的。

## 微调（需要时）

```bash
python -m openfold3.train \
  --config configs/finetune.yaml \
  --train_data /path/to/pairs \
  --resume_from_checkpoint of3_base.pt \
  --seed 42
```

微调的四条纪律：

1. **先切分再看数据。** 按序列相似性聚类划分训练/验证（不是随机划分），否则同源体分散
   在两侧，验证指标虚高。用 MMseqs2 在 30% 同一性上聚类是常见做法。
2. **验证集在整个过程里只用于选 checkpoint**，最终报告用独立测试集。
3. **报告基线。** 微调后的数字要与「同一测试集上现成权重的数字」并列，否则读者无从判断
   微调有没有用。
4. **记录一切**：配置文件、数据切分清单、随机种子、checkpoint 步数。见
   `ml-eval-protocol` 与 `reproducibility-checklist`。

## 与同类的取舍

| 需求 | 用 |
| --- | --- |
| 纯蛋白，最成熟稳定 | `alphafold2` |
| 蛋白 + 配体 + **亲和力数值** | `boltz-2` |
| 需要**实验约束**引导、或离线单序列 | `chai-1` |
| 需要**离子/修饰/核酸**齐全、或需要**微调** | OpenFold3 |
| 高通量粗筛 | `esmfold` |

## 验证清单

- [ ] 确认用的是 OpenFold3 而不是 OpenFold（AF2 复现）
- [ ] `num_diffusion_samples` ≥ 5，seed 固定并记录
- [ ] 界面判据用链对 ipTM 分解
- [ ] 金属/辅因子用 `ccd` 而不是 SMILES 手写
- [ ] **权重许可查过并记录**（来源 URL + 条款）
- [ ] 做基准时用了训练截止之后的结构，且关了模板
- [ ] 微调时：按相似性聚类切分、报了现成权重的基线、记录了切分清单与种子

## 存成制品

存：输入 JSON、全部采样的 mmCIF、置信度文件、seed、完整命令行、**权重来源与许可记录**。
最后一项是这个技能特有的：它不是技术产物但是合规证据，事后补不回来。
