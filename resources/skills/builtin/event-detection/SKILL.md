# 睡眠事件检测

覆盖纺锤波、慢波、觉醒、呼吸事件。核心纪律是**先定义再检测**：任何一个检测器的输出
只在它的判据下有意义，而不同判据给出的密度能差两倍以上。

## 纺锤波

```python
import yasa
sp = yasa.spindles_detect(data, sf, ch_names=chan, hypno=hypno, include=(2, 3))
summary = sp.summary()          # 每个事件一行：起止、时长、频率、幅度、RMS
density = sp.summary(grp_chan=True)['Density']   # 每分钟个数
```

- **必须限定睡眠期。** `hypno=` + `include=(2, 3)` 把检测限制在 N2/N3。不限定会在清醒期
  的 α 活动上产生大量假阳性——α 与 σ 频段重叠。
- **密度的分母是该期的时长，不是整夜。** yasa 的 `Density` 已经按 `include` 的时长算，
  自己实现时别忘了。
- 判据的关键参数：频段（11-16 Hz）、时长（0.5-2 s）、相对功率阈值、相关系数阈值。
  把这四个值写进方法学描述。
- **检测器之间不可比。** yasa、Wamsley、Ferrarelli、Molle 的检测器在同一份数据上密度
  能差 2-3 倍。跨研究比较密度绝对值是没有意义的，只能比组间差异的方向与效应量。

## 慢波

```python
sw = yasa.sw_detect(data, sf, hypno=hypno, include=(2, 3), freq_sw=(0.3, 1.5),
                    dur_neg=(0.3, 1.5), dur_pos=(0.1, 1), amp_ptp=(75, 350))
```

- `amp_ptp` 下限 75 µV 是 AASM 的慢波判据。放宽到 40 µV 会把大量 δ 波动算进来，
  密度翻倍——这是文献里慢波密度差异巨大的主因之一。
- 报告时区分 **慢振荡**（<1 Hz，与 K 复合波相关）与 **δ 波**（1-4 Hz）。合成一类会
  掩盖它们在老化研究里的不同变化方向。
- 输出里的 `PTP`、`Slope`、`Frequency` 是慢波形态指标；斜率对年龄敏感，比密度更稳。

## 纺锤波—慢波耦合

```python
coupling = yasa.sw_detect(..., coupling=True).summary()['PhaseAtSigmaPeak']
```

耦合相位的统计**必须用圆统计**（Rayleigh 检验、平均向量长度），不能算算术平均——
0° 与 359° 的算术均值是 180°，正好是相反的结论。用 `scipy.stats.circmean` 与
`pingouin.circ_rayleigh`。

## 觉醒

AASM 定义：从睡眠中出现持续 ≥3 s 的 EEG 频率突然移向 α/θ/>16 Hz（不含纺锤波），
且在 REM 期还要求同时有 ≥1 s 的 EMG 升高。

- 自动检测的一致性远低于纺锤波，人工判读仍是主流。自动结果要标注为自动。
- **觉醒指数** = 觉醒次数 / TST（小时）。分母用 TST，不是 TIB。

## 呼吸事件

- **呼吸暂停**：气流下降 ≥90%，持续 ≥10 s。
- **低通气**：气流下降 ≥30% 且伴血氧下降 ≥3%（AASM 2012 推荐）或伴觉醒。
  **≥4% 是替代判据**，两者算出的 AHI 能差 30% 以上，必须写明用的哪一套。
- **AHI** = (呼吸暂停 + 低通气) / TST（小时）。用记录时长做分母会系统性低估。
- 血氧信号采样率通常 1 Hz 且带内置平均，下降幅度对平均窗口敏感。

## 通用纪律

1. **报告密度而不是计数。** 记录时长不同时计数不可比。
2. **人工核验一小段。** 随机抽 10 个检测到的事件画出来目视确认，把这张图存成制品。
   检测器参数配错时输出仍然「看起来合理」，只有看波形才能发现。
3. **假阳性与漏检的代价不对称。** 研究组间差异时漏检（降低灵敏度但一致）比假阳性
   （引入与分组相关的噪声）危害小。
4. **事件表存成制品并带上检测参数**。事件表是后续统计的输入，参数丢了整条链不可复现。
