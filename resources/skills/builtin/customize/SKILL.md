# 平台定制

## 数据目录

一切都在 `%LOCALAPPDATA%\L-science`（可用 `L_SCIENCE_DATA_DIR` 覆盖）：

```
config\app.db              项目注册表、供应商与模型、技能、连接器、算力、全局记忆
credentials\vault.bin      DPAPI 加密的凭据（在仓库之外，不可能被误提交）
projects\<id>\project.db   单个项目：会话、制品与血缘、计划、审查、路由决策
projects\<id>\blobs\       内容寻址的制品内容
projects\<id>\workspace\   各会话的工作目录
skills\builtin\<slug>\     内置技能（平台所有，升级时会被覆盖）
skills\user\<slug>\        用户技能（不会被覆盖）
runtime\                   内核连接文件与临时环境
```

备份只需要这一个目录。**凭据库跨机器无法解开**（DPAPI 密钥绑定用户与机器），
换机器要重新录入密钥。

## 自建技能

在 `skills\user\<slug>\` 下建目录，两个文件必需：

```
skills\user\my-method\
  SKILL.md          主指令文档，front matter 含元数据
  skill.json        结构化清单
  references\       可选，按需二次加载
  scripts\          可选
```

`skill.json` 的字段：

```json
{
  "slug": "my-method",
  "name": "我的方法",
  "version": "1.0.0",
  "domain": "信号与数据",
  "description": "一句话说清它做什么。这是检索的主要输入，不能为空。",
  "triggers": [
    "什么时候该用它，按用户会怎么说来写",
    "多写几条不同说法，覆盖率更高"
  ],
  "requires": {
    "python": ["mne"],
    "r": [],
    "commands": ["pandoc"],
    "capabilities": ["kernel:python"],
    "connectors": []
  },
  "tools": ["python", "save_artifacts"]
}
```

**`triggers` 写「什么时候用」而不是「它是什么」。** 检索的输入是用户的话，
而用户说的是自己的目的。`description` 写成定义、triggers 写成场景，两者分工不同。

**覆盖内置技能**：在 `skills\user\` 下用**相同的 slug** 建目录即可。
覆盖是整体替换而非字段合并——把内置的两个文件复制过去再改，不要只放一个 `skill.json`。
设置页会显示哪些内置技能被遮蔽了。

改完在设置页点重新扫描（或重启后端）生效。清单有语法错误时该技能不会加载，
但其余技能不受影响，错误会在设置页与日志里报出来。

## 供应商与模型

登记供应商（含基地址）**只在命令行做**：

```
node scripts/provision.mjs
```

这一步刻意不放进界面：基地址决定「把数据发给哪个服务器」，
不该由渲染层任意指定。

界面上（设置页）能做的：

- 启用/禁用供应商与逐个模型
- 绑定凭据引用名
- 同步模型列表（向供应商查询当前可用型号，线上消失的会被禁用而不是删除）
- 健康检查（结果记到该供应商的每个模型上，五分钟后过期）

## 凭据

设置页录入，DPAPI 加密后落盘。**界面永不回显密钥**，只显示长度与末四位。
命令行方式：

```
node scripts/credential.mjs set provider:deepseek     # 密钥从环境变量读，不进命令行参数
node scripts/credential.mjs list
```

密钥不进命令行参数是刻意的：参数会进进程列表与 shell 历史。

被供应商引用中的凭据不能直接删除，要先解绑。

## 路由

平台按任务类型选模型。十三种任务各有能力权重预设（推理、写代码、数学、长文召回、
中英写作、工具调用、结构化输出、引文可靠性、指令跟随），再减去归一化后的成本与延迟惩罚。

在「模型路由」视图可以：

- **试算**：看当前设置会选谁、各候选得分构成、谁被排除及原因、预估成本。试算不调用模型。
- **覆盖权重**：拖动滑块。覆盖是**替换**整张权重表而不是合并——这样才能表达
  「把某个维度调到 0」。
- **强制指定模型**：仍会走硬过滤（可以指定模型，不能指定物理上做不到的组合，
  比如让纯文本模型读图）。
- **覆盖任务类型**：任务类型默认由内容推断（关键词匹配，覆盖率有限），可以直接指定。

覆盖**按回合生效，发完即失效**。生效时输入框上方会有提示条。

## 记忆与授权

- **记忆**：三层作用域（全局、项目、算力目标）。每条写入都要有理由，可在界面上审查与编辑。
- **宿主路径授权**：访问沙箱外的路径需要审批，授权可按次/会话/项目/永久，随时可撤销。
- **域名白名单**：内核的网络出口经代理管控，白名单外的域名会触发审批。
  回环地址无条件放行（本机 Ollama 必须可达）。

三者都在设置与工具视图里可查看与撤销。

## 沙箱后端

`npm run doctor` 会给出建议后端：

- **wsl2**：强隔离（独立文件系统与网络命名空间）。推荐。
- **docker**：强隔离，需要 Docker Desktop 运行。
- **native**：零安装，但**文件边界只靠工具层校验，内核内的代码可以绕过**；
  网络出口是代理级管控，直接建 socket 可绕过。隔离强度在界面上常驻显示，不会被美化。
