# 伦理与知情同意

**本技能提供的是稿件中相关章节的写作规范，不构成法律或伦理审查意见。**
具体合规要求由所在机构的伦理委员会与当地法规决定，必须以他们的意见为准。

## 稿件里必须出现的四项

多数期刊把这四项列为必填，缺一项会被退回：

1. **伦理批准**：委员会名称 + 批件编号。
2. **知情同意**：形式（书面/口头）与特殊情形（未成年人、无行为能力者）。
3. **声明遵循的准则**：赫尔辛基宣言（人类受试）或相应动物准则。
4. **注册**：临床试验注册号（干预性研究通常强制）。

```
本研究经{机构名}伦理委员会批准（批号 {编号}），
按《赫尔辛基宣言》原则实施。所有参与者在参与前签署书面知情同意书。
本研究已在中国临床试验注册中心注册（ChiCTR{编号}，注册日期 {日期}）。
```

## 批号与委员会名称不能凭记忆写

**批件编号必须来自实际批件文件。** 写错一位数字，期刊核查时会要求提供批件，
而不一致会引发严重的诚信质疑。拿不到确切编号时留占位符
`[待填：伦理批号，见批件文件]`，不要填一个格式看起来对的数字。

同样适用于试验注册号、基金编号、以及委员会的正式名称
（「XX 医院伦理委员会」与「XX 医院医学伦理委员会」是不同的名称）。

## 知情同意的特殊情形

| 情形 | 表述要点 |
|---|---|
| 未成年人 | 监护人签署同意 + 儿童本人的知情赞同（assent），两者都要写 |
| 无行为能力者 | 法定代理人同意；说明如何评估能力 |
| 回顾性数据 | 说明是否获得伦理委员会的知情同意豁免及理由 |
| 公开数据集 | 说明原始研究已获批准，本次二次分析的审批状态 |
| 可识别信息发表 | 需单独的发表同意（publication consent），尤其是病例报告与影像 |

**回顾性研究的知情同意豁免必须写明**，不能只说「本研究为回顾性研究」——
豁免是伦理委员会做的决定，要引用它。

## 数据共享与同意的关系

这是最容易在投稿阶段才发现的冲突：**知情同意书里没写「数据可能被去标识后公开共享」时，
公开数据是违规的。**

因此：

- 研究设计阶段就在同意书里加入数据共享条款（若计划共享）。
- 已经收完数据才发现同意书不支持共享，唯一合规路径是受限访问
  （见 `data-availability-statement`），不要「反正去标识了应该没问题」。
- 生理信号的可识别性在不同法规下判定不同。PSG 原始波形是否属于可识别信息、
  是否属于生物识别数据，要问伦理委员会而不是自行判断。

## 二次分析

用他人数据集时要说明两层审批：

```
本研究为二次分析，使用 {数据集名}（版本 {号}）。原始数据采集经 {原机构}
伦理委员会批准，参与者已同意数据用于后续研究。本次分析经 {本机构}
伦理委员会审查并获知情同意豁免（批号 {编号}）。
```

**「用的是公开数据所以不需要伦理审批」在多数机构不成立。** 是否需要审批由本机构决定，
多数情况需要一个审查记录（即便结论是豁免）。

## 利益冲突与资助

```
利益冲突：作者 A 曾接受 {公司} 的讲课费；其余作者声明无利益冲突。
资助：本研究由 {基金名}（编号 {号}）资助。资助方未参与研究设计、
数据收集与分析、稿件撰写及投稿决定。
```

- **「无利益冲突」也要显式声明**，留空会被退回。
- 三年内的相关经济关系通常都要披露（各刊时限不同，核对指南）。
- 资助方参与了设计或分析时必须如实写出，不能套用「未参与」的模板句。

## 作者贡献（CRediT）

越来越多期刊要求按 CRediT 分类列出：

```
作者贡献：A：概念化、方法学、撰写初稿；B：数据采集、调查；
C：形式分析、可视化；D：监督、经费获取、审阅与编辑。
```

14 个 CRediT 角色：Conceptualization、Data curation、Formal analysis、
Funding acquisition、Investigation、Methodology、Project administration、
Resources、Software、Supervision、Validation、Visualization、
Writing – original draft、Writing – review & editing。

**AI 工具不是作者。** 多数期刊（含 ICMJE 立场）明确规定 AI 不能列为作者，
但要求在方法或致谢中披露其使用方式。本平台的使用应据此披露，例如：

> 本研究在数据分析与稿件起草过程中使用了 AI 辅助工具（{平台名}）。
> 全部分析代码、统计结果与结论均经作者核验，作者对内容的准确性承担全部责任。
