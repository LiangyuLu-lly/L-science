# 多重比较校正

## 什么时候必须校正

只要**同一个研究问题被检验了多次**：多个通道、多个频段、多个时间点、多组两两比较、
多个结局指标。20 次独立检验在零假设全真时至少出现一个 p<0.05 的概率是 64%。

**校正家族按「研究问题」而不是按「表格」界定。** 这是最容易被绕过的一条：把六个通道
的检验分到两张表里，然后各自不校正，家族并没有变小。判断标准是：如果这些检验里任何
一个显著你都会写进结论，那它们就是一个家族。

不需要校正的情况：**预注册的单一主要结局**。此时其余指标是探索性的，报告时明确标注为
探索性且不做推断性声明。

## 选方法

| 情形 | 方法 | 理由 |
|---|---|---|
| 少量（<10）预设比较，要严格控制假阳性 | Holm | 一致优于 Bonferroni，同样控制 FWER |
| 大量检验，探索性，能容忍部分假阳性 | Benjamini-Hochberg（FDR） | 检验力高得多 |
| 检验之间强相关（相邻通道、相邻时间点） | 簇水平置换检验 | 利用相关结构，不做独立性假设 |
| 多组两两比较（方差分析事后） | Tukey HSD | 专为此设计 |
| 与单一对照组比较 | Dunnett | 比较数更少，检验力更高 |

```python
from statsmodels.stats.multitest import multipletests
reject, p_adj, _, _ = multipletests(pvals, alpha=0.05, method='holm')   # FWER
reject, p_adj, _, _ = multipletests(pvals, alpha=0.05, method='fdr_bh')  # FDR
```

**Bonferroni 几乎总有更好的替代品。** Holm 在完全相同的假设下更有力，没有理由再用
Bonferroni——除非需要它的简单性来做样本量估算。

## FWER 还是 FDR

- **FWER**（族内至少一个假阳性的概率）：确认性研究、要下明确结论的主要分析。
- **FDR**（被拒绝的假设中假阳性的期望比例）：探索性筛查、检验数上百上千。

两者不可混用于同一家族。**报告时必须写明控制的是哪一个**——「校正后 p<0.05」不说明
控制的是什么，等于没说。

## 强相关数据：簇水平置换检验

多通道 × 多时间点 × 多频率的数据上，逐点校正（Bonferroni 或 FDR）会因为极端保守而
几乎检不出任何东西。标准做法是簇水平置换检验：

```python
from mne.stats import permutation_cluster_1samp_test
t_obs, clusters, cluster_p, _ = permutation_cluster_1samp_test(
    X, n_permutations=5000, threshold=None, tail=0, adjacency=adjacency, seed=42)
```

三个必须报告的参数：

1. **簇形成阈值**（cluster-forming threshold）。它不是显著性阈值，改变它会改变检出的
   簇的大小与位置。常用 p<0.05 对应的 t 值。
2. **置换次数**。5000 次以上；1000 次时最小可达 p 值是 0.001，分辨率不足。
3. **邻接结构**（adjacency）。通道的空间邻接由 montage 决定，`mne.channels.find_ch_adjacency`。

**簇水平检验的结论只能是「这个簇整体上显著」**，不能说「某个通道在某个时刻显著」。
把簇的边界当成效应的精确时空范围是对该方法的过度解读——这一点在方法学文献里被反复强调。

## 校正之后不显著了怎么办

这是正确的结果，不是问题。可以做的：

- **报告效应量与置信区间**，让读者判断实际意义。校正影响的是推断，不是估计。
- 如实标注为探索性发现，说明需要独立样本验证。
- 检查是不是检验太多了——把结局指标从十个减到一个预注册的主要指标，检验力立刻回来。

**不可以做的**：换一个更宽松的校正方法然后只报那个；把家族拆小；改成单尾检验；
删掉「异常」被试。这些都是 p-hacking，且在有版本历史的项目里可被追溯。

## 报告模板

> 对 6 个通道 × 3 个频段共 18 次比较采用 Holm 校正控制族内一类错误率（FWER）在 0.05。
> 校正后 C3-M2 的 σ 功率组间差异显著（t(28) = 3.42，p_adj = .012，Cohen's d = 0.87，
> 95% CI [0.31, 1.42]）；其余比较不显著（全部 p_adj > .18）。

不显著的那些也要给出汇总（至少给最小的 p_adj），否则读者无法判断是否存在选择性报告。
