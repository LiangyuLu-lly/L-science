# 系统综述与 PRISMA

## 顺序不可颠倒

1. **预注册**（PROSPERO），拿到注册号。
2. 定 PICO 与纳入排除标准。
3. 检索（见 `literature-search`）。
4. 去重（见 `reference-dedupe`）。
5. 双人独立筛选：标题摘要 → 全文。
6. 数据提取（双人）。
7. 偏倚风险评估。
8. 综合（叙述性或元分析）。
9. 证据确定性评级（GRADE）。

**预注册必须在筛选开始之前完成。** 事后注册会被期刊查出（PROSPERO 有时间戳），
而「先看了结果再定纳入标准」是系统综述里最严重的偏倚来源。

## PICO 与纳入排除

```
P（人群）: 18-65 岁原发性失眠（DSM-5 或 ICSD-3 诊断）
I（干预）: CBT-I，≥4 次会谈，任何递送方式
C（对照）: 等待列表、常规护理或安慰对照
O（结局）: 主要 = PSG 测得的 TST；次要 = SE、SOL、ISI 评分
研究类型: 随机对照试验
排除: 共病未控制的 OSA；单次会谈干预；仅自报结局
```

每一条排除标准都要能**在筛选时机械地判定**。「质量太低」不是可操作的标准——
质量由偏倚风险评估表达，不是纳入标准。

## 双人筛选

- 两人独立筛，记录**一致性（Cohen's κ）**。κ<0.6 说明标准不够清晰，回去修标准并重筛，
  而不是靠讨论逐条解决。
- 分歧由第三人裁决或讨论达成一致，**记录分歧数量**。
- 排除理由要分类记录（PRISMA 流程图的全文排除框需要「排除 n 篇，理由分别是……」）。

## PRISMA 2020 流程图

四层，每一层的数字要能相互推导：

```
识别：数据库 (n = 1251)  其他来源 (n = 23)
  ↓ 去重 (n = 389 removed)
筛选：标题摘要筛选 (n = 885)
  ↓ 排除 (n = 792)
全文评估：(n = 93)
  ↓ 排除 (n = 71，理由：非 RCT 32、结局不符 21、人群不符 12、全文不可得 6)
纳入：(n = 22)，其中进入元分析 (n = 18)
```

**「进入元分析」与「纳入综述」常常不同**（有的研究缺少可合并的效应量）。
两个数都要给，且差额要解释。

## 偏倚风险

按研究类型选工具，不要混用：

| 研究类型 | 工具 |
|---|---|
| 随机对照试验 | RoB 2 |
| 非随机干预研究 | ROBINS-I |
| 观察性（队列、病例对照） | Newcastle-Ottawa 或 ROBINS-E |
| 诊断准确性 | QUADAS-2 |

结果用 traffic-light 图呈现（逐研究 × 逐领域）。**不要把各领域评级加总成一个分数**
——RoB 2 明确反对总分，因为一个领域的高风险足以让整个结果不可信，加总会把它平均掉。

## 元分析

```python
# 随机效应（DerSimonian-Laird 或 REML），生理/行为干预几乎总该用随机效应
# 固定效应假定所有研究估计同一个真值，这在不同人群与方案的研究间不成立
```

- **异质性**：报告 I²、τ²、Q 检验与 **预测区间**。I² 是比例不是绝对量，
  研究量少时它的置信区间极宽——只报 I²=45% 而不给区间是不充分的。
- **预测区间比置信区间更重要**：置信区间说的是「平均效应在哪」，
  预测区间说的是「下一个研究的效应可能在哪」。异质性大时后者常跨过 0，
  这个事实必须让读者看到。
- **亚组分析与元回归必须预注册**。事后亚组分析是探索性的，要标注，且每增加一个亚组
  就多一次多重比较。
- **研究数少于 10 篇时不做漏斗图与 Egger 检验**（Cochrane 建议），检验力不足到毫无意义。
- 单个研究权重超过 50% 时做敏感性分析（去掉它看结论是否翻转）。

## GRADE

对每个结局给出确定性等级（高/中/低/极低），从 RCT 的「高」起降级：

- 偏倚风险、不一致性（异质性大）、间接性（人群/干预不完全匹配）、
  不精确性（置信区间宽或事件数少）、发表偏倚。

**降级理由要逐条写出来。** 只给一个「证据确定性：低」不说明为什么，评审时会被追问。

## 存成制品

检索式与命中数、去重映射、筛选决策表（含双人评分与 κ）、提取表、偏倚风险评分表、
流程图、森林图（带代码）。系统综述的可复现性要求高于普通研究——PRISMA 条目清单本身
也应作为补充材料提交。
