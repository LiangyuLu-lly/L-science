# 论文起草

## 硬约束

**不得生成任何不来自实际分析的数字、也不得生成任何未经核实的引文。**

需要一个数而手头没有时，写占位符并说明：

```
N3 时长在干预组减少了 [待填：从 sleep_stats.csv 的 group 差异取值] min
```

不要写一个「看起来合理」的数。占位符会被看见并填上，编造的数会一路留到投稿。
引文同理——需要引用时先用 `citation-verify` 取证，拿不到证据就标 `[需核实引文]`。

## 写作顺序

按信息确定性从高到低写，不按阅读顺序：

1. **方法**（已经做完的事，最容易写，且写的过程会暴露遗漏的参数）。
2. **结果**（数据已在手）。
3. **图表**（结果写完才知道需要哪几张）。
4. **讨论**。
5. **引言**（放到这里写：读完自己的讨论之后，才知道该把哪个空白突出出来）。
6. **摘要**（全文定稿后压缩）。
7. **标题**（最后）。

先写引言的常见后果是它与最终结论不匹配——铺垫的空白不是最后填上的那个。

## 段落结构

每段一个论点，主题句在**段首**。审稿人和多数读者会扫读段首句，
把关键结论埋在段中会被漏掉。

```
[主题句：这一段要说的结论]
[证据：数据、引文]
[必要的限定或对立证据]
[（可选）过渡到下一段]
```

段落长度控制在 4-8 句。超过 10 句通常说明装了两个论点，该拆。

## 时态

- **方法**：过去时（`Participants completed…`）。
- **结果**：过去时（`TST increased by 34 min`）。
- **图表指代**：现在时（`Figure 2 shows…`）——图表现在就在那里。
- **既有知识**：现在时（`CBT-I is an established treatment`）。
- **具体的既有研究**：过去时（`Smith et al. reported…`）。
- **讨论中的推断**：现在时或情态（`These results suggest…` / `may reflect`）。

## 语态

主动语态更清楚，且多数期刊已明确接受第一人称：`We recruited 44 participants`
优于 `Forty-four participants were recruited`（后者隐藏了施动者，
且在方法里会造成「谁做的判读」不清）。

例外：动作的执行者不重要时用被动更自然（`Signals were band-pass filtered at 0.3-35 Hz`）。

## 统计量的写法

```
t(42) = 3.21, p = .002, Cohen's d = 0.98, 95% CI [0.34, 1.61]
F(2, 84) = 5.67, p = .005, η²p = .12
χ²(1) = 8.71, p = .003, OR = 2.31, 95% CI [1.32, 4.04]
β = 0.24, SE = 0.08, t(126) = 3.00, p = .003
```

格式惯例（APA / 多数医学期刊）：

- **p 值**：小数点前不写 0（`p = .002`）；小于 .001 写 `p < .001`；
  不写 `p = .000`（那是舍入结果，不是零）。
  不写 `p = NS`——给出具体值，读者需要它做元分析。
- **统计量符号斜体**（*t*、*p*、*F*、*d*、*r*），自由度不斜体。
- **置信区间用方括号**，两端都给，不写 `±`。
- **有效位数**：p 值三位小数；效应量两位；描述统计与测量精度匹配
  （TST 用分钟取整，不写 342.7183 min）。
- **每个 p 值旁边必须有效应量**。只报 p 值的稿件会被直接要求补。

## 数字与单位

- 句首的数字用英文单词拼写（`Forty-four participants`）。
- 单位与数值间加空格（`30 s`、`75 µV`），百分号不加（`38%`）。
- 中文稿里数字与中文之间加空格：`共 44 名被试`。
- 均值 ± 标准差 要说明是 SD 还是 SEM。**默认写 SD**，用 SEM 必须明确标注
  ——SEM 看起来更小，用它而不标注会被认为是在美化离散度。

## 图表引用

正文必须引用每一张图表（`（图 2）` / `(Figure 2)`），且编号按首次出现顺序。
图表不能只在补充材料里被引用一次而正文不提。

## 交叉核对

初稿完成后逐项核：

1. 摘要里的每个数 ↔ 结果里的对应数字（**逐个核对，不要抽查**）。
2. 每个数字 ↔ 产出它的制品与代码（血缘完整吗）。
3. 每条引文 ↔ 核实记录。
4. 图表编号连续、正文都有引用。
5. 缩写首次出现处有全称。

这一步交给 Reviewer 跑一遍会更可靠——数字在正文/表/图之间不一致是它的检查项之一。
