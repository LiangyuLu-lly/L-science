# 体动记录仪分析

## 它能回答与不能回答的问题

**能**：睡眠时段（在床/离床、入睡与起床时刻）、总睡眠时间的近似、昼夜节律的稳定性
与碎片化、跨多日的规律性。

**不能**：睡眠分期。体动记录**无法区分 NREM 各期与 REM**。任何声称从腕表得到「深睡
时长」的输出都是厂商算法的推断，不是测量，写进论文必须标注为估计且引用其效度研究。

对失眠人群的关键限制：**安静清醒会被判成睡眠**。因此体动记录系统性高估 TST、
低估 WASO，且这个偏差与失眠严重程度相关——组间比较时它不是随机噪声。

## 数据准备

原始输出通常是每分钟一个 activity count（不同厂商的 count 定义不同，**不可跨设备比较**）。

```python
import pandas as pd
df = pd.read_csv(path, parse_dates=['timestamp']).set_index('timestamp')
counts = df['activity'].resample('1min').sum()      # 统一到 1 min epoch
```

**non-wear 检测**：连续 ≥60 min 的零 count 视为未佩戴。它与「睡得很沉」的区别是
后者仍有零星微动。

```python
zero_run = (counts == 0).astype(int).groupby((counts != 0).cumsum()).cumsum()
nonwear = zero_run >= 60
```

**纳入标准要预先定好并写进方法**：常见是「每 24 h 至少佩戴 16 h，且至少 5 个有效日
（含至少 1 个周末日）」。事后调整标准是 p-hacking 的一种形式。

## 睡眠/清醒判定

Cole-Kripke（1992）加权和判据，被广泛使用：

```python
# D = 0.001 * (106*A(-4) + 54*A(-3) + 58*A(-2) + 76*A(-1) + 230*A + 74*A(+1) + 67*A(+2))
w = np.array([106, 54, 58, 76, 230, 74, 67])
D = 0.001 * np.convolve(counts, w[::-1], mode='same')
sleep = D < 1.0        # D < 1 判为睡眠
```

Sadeh（1994）算法在儿童与青少年上验证更充分。**选哪个要写明，并说明验证人群与你的
样本是否一致**——在老年失眠人群上用儿童验证的算法是常见但少有人声明的问题。

**在床时段必须另行确定**，判定算法本身不给。三种来源：睡眠日志（金标准）、
设备的事件按钮、算法推断。有日志时以日志为准，并报告日志与算法的一致性。

## 昼夜节律指标

以 24 h 平均活动曲线为基础：

- **IS（interdaily stability）**：跨日一致性，0-1，越高越规律。
- **IV（intradaily variability）**：日内碎片化，相邻 epoch 一阶差分的方差比。
  值越高说明活动—休息切换越频繁。
- **M10**：一天中最活跃的连续 10 h 的平均活动。**L5**：最不活跃的连续 5 h。
- **RA（relative amplitude）** = (M10 − L5) / (M10 + L5)，0-1。

```python
# IV：注意分母是整段方差，分子是一阶差分的均方
iv = np.mean(np.diff(counts) ** 2) / np.var(counts)
```

**余弦拟合（cosinor）**：`activity ~ M + A*cos(2π(t − φ)/24)`。人的活动曲线并不像余弦
（起床是陡变），因此 R² 常低于 0.5。扩展余弦（anti-logistic transformed cosine）更贴合，
但增加了参数。报告 R² 让读者判断拟合是否可信。

**MSFsc（睡眠中点，校正睡眠债）**：来自 MCTQ 的时型指标。工作日与自由日分开算，
自由日中点按睡眠债校正。这是时型研究的标准指标，别用「平均入睡时间」代替。

## 分析纪律

- **分析单位是被试**，不是日。多日数据用混合效应模型，被试作随机截距（见
  `mixed-effects-models`）。
- **夏令时与时区**。跨时区旅行或 DST 切换会在时间轴上造出一小时的跳变。用带时区的
  时间戳，且在方法里说明如何处理。
- **缺失日不要用零填充**。零 count 会被判成睡眠，直接把缺失日变成一整天的睡眠。
- 与 PSG 比较时报告 **逐 epoch 的灵敏度、特异度与准确率**，而不只是 TST 的相关系数。
  灵敏度（判睡为睡）通常 >0.9，特异度（判醒为醒）常低于 0.5，只报相关系数会掩盖这一点。

## 存成制品

每分钟 epoch 表、non-wear 掩码、在床时段来源、判定算法与参数、有效日数，以及
