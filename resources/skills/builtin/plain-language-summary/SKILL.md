# 通俗摘要

## 目标与红线

目标：让没有专业背景的读者（患者、家属、记者、资助方）准确理解做了什么、
发现了什么、这对他们意味着什么。

**红线：通俗化不等于放宽结论。** 最常见的失效模式是「去掉限定词让句子更好读」，
结果把「在 60-75 岁原发性失眠患者中，8 周 CBT-I 使总睡眠时间平均增加 34 分钟」
写成「认知行为治疗能改善睡眠」——后者听起来更清楚，但它把人群、干预时长、
效应大小全部丢掉了，而这三项恰恰决定它是否适用于读者自己。

## 结构（150-250 词）

1. **问题**：为什么这件事重要，与读者的关系。
2. **做了什么**：多少人、什么设计、多久。
3. **发现了什么**：主要结果，给可理解的数量（分钟、百分比），不给统计量。
4. **这意味着什么**：适用范围明确的一两句。
5. **限制**：一句，说清最重要的那条。

## 术语替换

| 专业表述 | 通俗表述 |
|---|---|
| 多导睡眠图（PSG） | 在睡眠实验室里同时记录脑电、眼动、肌肉活动和呼吸的检查 |
| 慢波活动 | 深睡期特有的大而缓慢的脑电波 |
| 睡眠效率 | 躺在床上的时间里真正睡着的比例 |
| 入睡潜伏期 | 从关灯到睡着所用的时间 |
| 随机对照试验 | 参与者被随机分到治疗组或对照组的研究 |
| 统计学显著 | （**删掉，不要替换**，见下） |
| 效应量 d=0.8 | 差异相当于……（用可理解的单位表述） |

**「统计学显著」不要翻译成「明显」「显著改善」。** 它在日常语言里表示「效果很大」，
而在统计里只表示「不太可能是偶然」。正确做法是**直接给效应大小**：

- 差：「治疗显著改善了睡眠。」
- 好：「治疗组每晚平均多睡 34 分钟，对照组几乎没有变化。」

## 数量的表达

- 用**绝对数量**而不只是相对变化。「风险降低 50%」可能是从 2% 降到 1%，
  绝对差异只有 1 个百分点。两个都给：「从 100 人中约 2 人降到约 1 人（相对降低约一半）」。
- 用**自然频率**而不是概率：「1000 人中有 3 人」比「0.3%」更易理解。
- 不确定性要保留但换个说法：把「95% CI [18, 50]」写成
  「真实效果大约在每晚多睡 18 到 50 分钟之间」。

## 句式

- 一句话一个意思，20-25 字以内。
- 主动语态，具体主语（「我们招募了 44 位……」）。
- 避免嵌套从句与并列长串。
- 缩写首次出现给全称，之后尽量继续用中文表述而不是缩写。

## 适用范围

必须写清研究的人群，且不要暗示可以外推：

> 本研究的参与者是 60 至 75 岁、被诊断为原发性失眠且没有严重睡眠呼吸暂停的成年人。
> 结果不一定适用于年轻人、或同时患有其他睡眠疾病的人。

## 不能做的事

- **不给医疗建议。** 「如果你失眠，应该尝试 CBT-I」超出了研究结论的范围，
  也超出了论文的角色。改成「本研究支持 CBT-I 在这一人群中的效果；
  是否适合个人情况需与医生讨论」。
- **不承诺未来。** 「这项发现将带来新的治疗方法」是推测。
- **不省略负面结果。** 次要结局没有差异这件事同样要写，否则是选择性呈现。
- **不用「突破」「首次证明」这类词**，除非稿件本身就是这么写的且站得住。

## 自查

- 一个没有医学背景的人读完能说出「研究了谁、发现了什么」吗？
- 每个效应都给了可理解的数量吗？
- 人群与适用范围写清了吗？
- 有没有出现比正文更强的结论？（逐句与摘要比对）
- 有没有暗示医疗建议？
