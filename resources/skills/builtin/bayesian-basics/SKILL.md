# 贝叶斯基础

## 什么时候值得用

- **需要「支持零假设」的证据。** p>0.05 不是零假设为真的证据，它只是「没检出」。
  贝叶斯因子能区分「支持零假设」与「数据不足」，这是频率派做不到的。
- **需要边做边看数据。** 贝叶斯推断没有「窥视惩罚」，可以按证据强度决定何时停止采样。
- **有真实的先验信息。** 元分析给出的效应量分布可以直接作为先验。
- **模型复杂、层级多**。层级模型在贝叶斯框架下更自然，收敛诊断也更透明。

**不值得用的情形**：只是因为 p 值刚好不显著就换成贝叶斯，然后报告「有中等证据支持
效应存在」。这与 p-hacking 同类，且审稿人一眼能看出来（尤其当预注册里写的是频率派）。

## 贝叶斯因子

```r
library(BayesFactor)
bf <- ttestBF(x = group_a, y = group_b)     # 默认 Cauchy 先验，rscale = 0.707
bf                                           # BF10：支持备择相对零假设的倍数
1 / bf                                       # BF01：支持零假设
```

解释惯例（Lee & Wagenmakers）：

| BF10 | 含义 |
|---|---|
| 1-3 | 轶事级，基本没有信息 |
| 3-10 | 中等 |
| 10-30 | 强 |
| >30 | 很强 |

**BF10 在 1/3 到 3 之间的正确结论是「数据不足以区分」**，不是「无效应」。这是贝叶斯
分析最有价值的输出之一，别把它写成支持零假设。

**先验敏感性分析是必须的。** `rscale` 从 0.5 改到 1.0 能让 BF 变化数倍。
报告时给出至少三个先验宽度下的 BF，或画出 BF 随先验宽度变化的曲线。
不做敏感性分析的贝叶斯因子等于把结论建在一个未声明的任意选择上。

## 参数估计与可信区间

```python
import pymc as pm
with pm.Model():
    mu = pm.Normal('mu', 0, 10)
    sigma = pm.HalfNormal('sigma', 5)
    pm.Normal('y', mu, sigma, observed=data)
    idata = pm.sample(2000, tune=1000, chains=4, random_seed=42)

import arviz as az
az.summary(idata, hdi_prob=0.95)   # 后验均值、HDI、r_hat、ess
```

**报告 95% HDI（最高密度区间）而不是「贝叶斯置信区间」**，并说清它的含义：
「给定模型与先验，参数落在此区间的后验概率为 95%」。这与频率派置信区间的含义不同，
混用术语会被审稿人指出。

## 收敛诊断：不可省略

四项，缺一项结果就不可信：

1. **R̂（r_hat）< 1.01**。大于 1.05 说明链没混合，结果无效。
2. **有效样本量 ESS > 400**（每个参数）。ESS 远低于总抽样数说明自相关严重。
3. **发散转移（divergences）= 0**。有发散就要重参数化（非中心化）或提高 `target_accept`。
4. **轨迹图目视检查**（`az.plot_trace`）。四条链应该互相重叠成一片「毛毛虫」。

把诊断图存成制品。审稿人问「收敛了吗」时，一张轨迹图比任何文字都有说服力。

## 后验预测检查

```python
with model:
    pm.sample_posterior_predictive(idata, extend_inferencedata=True)
az.plot_ppc(idata)
```

它回答的是「这个模型能生成出像我的数据这样的数据吗」。模型误设（例如用正态模型
拟合右偏的潜伏期）在这里会明显暴露，而 R̂ 一切正常。**这一步比收敛诊断更容易被跳过，
也更容易发现真问题。**

## 先验的写法

必须在方法里逐个参数写出先验及其依据：

> 组间差异的先验取 Normal(0, 0.5)（标准化尺度），依据是 Smith 等（2021）元分析报告的
> 效应量 95% 区间 [0.41, 0.83]，我们取一个更宽、以 0 为中心的弱信息先验以避免把
> 元分析的乐观偏差带进来。

**「使用无信息先验」不是一个具体的先验。** 真正的无信息先验在多数参数化下不存在
（且往往不当）。写具体分布与参数。

## 与频率派并报

对同一分析同时给出两套结果是可接受且常受欢迎的做法，但要**预先声明哪一套是主要分析**。
事后挑更好看的那套报告，是选择性报告。
