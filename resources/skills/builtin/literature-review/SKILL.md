# 文献综述工作流

## 先定类型

三种东西经常被混为一谈，而它们的方法学要求差得很远：

| 类型 | 检索要求 | 是否需要预注册 | 用在哪 |
| --- | --- | --- | --- |
| **背景综述**（narrative） | 覆盖主要工作即可 | 否 | 论文引言、课题调研 |
| **系统综述**（systematic） | 可复现的检索式 + 完整 PRISMA 流程 | 通常需要（PROSPERO） | 独立发表的综述 |
| **范围综述**（scoping） | 系统检索但不做效应量合并 | 建议 | 领域地图、研究空白识别 |

**要做系统综述就去 `systematic-review-prisma`**，那里有完整的 PRISMA 流程与流程图要求。
本技能覆盖的是前两类，以及系统综述的前半段（检索到抽取）。

第一步永远是问清楚做哪种。用户说「帮我写个综述」时通常指背景综述，而按系统综述的标准
去做会花掉十倍时间；反过来把系统综述做成背景综述则无法发表。不确定就用 `ask_user` 问。

## 第 1 步：把问题拆成可检索的结构

自由文本的研究问题不能直接拿去检索。先拆：

- **干预/暴露类问题**用 PICO：人群、干预、对照、结局
- **机制类问题**拆成：实体（基因/蛋白/通路）、现象、系统（物种/细胞/组织）、方法
- **方法学问题**拆成：任务、方法族、评价指标、数据集

拆完把每个槽位展开成同义词组，包括：缩写与全称、英美拼写、旧称与新称、MeSH 主题词。
**这一步的完整度决定了检索的召回率上限**，后面所有步骤都无法弥补这里漏掉的词。

```python
concepts = {
    'population': ['obstructive sleep apnea', 'OSA', 'sleep apnoea', 'sleep-disordered breathing'],
    'exposure':   ['continuous positive airway pressure', 'CPAP', 'positive airway pressure'],
    'outcome':    ['cognitive function', 'cognition', 'neurocognitive', 'executive function'],
}
# 组内 OR，组间 AND
query = ' AND '.join('(' + ' OR '.join(f'"{t}"' for t in ts) + ')' for ts in concepts.values())
print(query)
```

## 第 2 步：多源检索

**至少两个来源**。单一数据库的覆盖有系统性缺口：PubMed 不含多数计算机与工程会议、
OpenAlex 覆盖广但元数据噪声更大、预印本只在特定源里。

| 来源 | 覆盖 | 用它的理由 |
| --- | --- | --- |
| PubMed / PMC | 生物医学期刊，MeSH 索引 | MeSH 主题词检索精度高，PMC 有全文 |
| OpenAlex | 跨学科，含引用图 | 覆盖最广，能做引文追踪 |
| bioRxiv / medRxiv | 预印本 | 最新工作；**必须标注未经同行评议** |
| ClinicalTrials | 注册试验 | 找未发表结果，识别发表偏倚 |
| arXiv | 计算方法 | 方法学类问题必查 |

检索用连接器完成（见 `search_skills` 里的连接器清单）。**每次检索都要记录**：来源、
完整检索式、日期、命中数。这三项缺一个，检索就不可复现。

```python
import pandas as pd
log = pd.DataFrame([
    {'source': 'pubmed',   'query': query, 'date': '2026-07-31', 'n': 412},
    {'source': 'openalex', 'query': query, 'date': '2026-07-31', 'n': 1087},
])
```

补充两条**不能省**的检索途径：

- **引文追踪**：对入选的核心文献做前向（谁引用了它）与后向（它引用了谁）追踪。
  纯关键词检索会漏掉用不同术语描述同一现象的工作，而引文网络能捞回来。
- **手工检查**：领域内标志性综述的参考文献列表。

## 第 3 步：去重

多源检索必然大量重复。去重规则按优先级：

1. **DOI 完全匹配**（归一化后：转小写、去 `https://doi.org/` 前缀）
2. **PMID / arXiv id 匹配**
3. **标题模糊匹配 + 年份接近**——处理 DOI 缺失与预印本/正式版配对

细节见 `reference-dedupe`。这里只强调一条：**预印本与其正式发表版本要合并为一条**，
并保留正式版为主记录。不合并会让同一项研究在证据表里被数两次，直接影响综述结论的分量。

## 第 4 步：两阶段筛选

先定纳入与排除标准，**再**开始筛。顺序反了就变成了「按结论挑文献」。

标准要具体到可判定：

```
纳入：成人（≥18 岁）；诊断明确的 OSA；含 CPAP 干预组与对照组；报告至少一项客观认知测评
排除：动物研究；病例报告与 n<10；仅报告主观量表；非英文/中文（并说明这个限制）
```

两阶段：

- **阶段一：标题与摘要。** 宁可放宽——这一阶段的错误里，误排除是不可逆的（后面不会再看到它），
  误纳入只是多花一点时间。
- **阶段二：全文。** 严格执行标准，**记录每一篇的排除原因**。PRISMA 流程图需要这些计数，
  背景综述也需要它来回答「为什么没引某篇」。

```python
screen = pd.DataFrame(columns=['id', 'title', 'stage', 'decision', 'reason'])
# decision ∈ {include, exclude}；exclude 必须有 reason
assert screen.loc[screen.decision == 'exclude', 'reason'].notna().all(), '排除必须写原因'
```

有条件时**双人独立筛选**并报 Cohen's κ。做不到（单人或 agent 完成）时如实写明这是单人筛选，
这是一个必须交代的局限。

## 第 5 步：结构化抽取

抽取表的每一行是一项研究，每一列是一个字段。**关键是每个数据点都带原文位置**：

```python
extract = pd.DataFrame(columns=[
    'id', 'doi', 'first_author', 'year', 'design',
    'n_total', 'n_intervention', 'n_control',
    'population_detail', 'intervention_detail', 'comparator',
    'outcome_measure', 'effect_estimate', 'ci_low', 'ci_high', 'p_value',
    'followup_months', 'funding', 'conflicts',
    'risk_of_bias', 'quote', 'page_or_section',   # ← 这两列是硬要求
])
```

`quote` 与 `page_or_section` 不是可选的。没有它们，综述里的每一句话都无法核对，
而**无法核对的引用与编造的引用在读者那里是同一件事**。

抽取纪律：

- **数字从原文抄，不从摘要抄**。摘要里的数字常与正文表格不一致（四舍五入、不同亚组）。
  不一致本身要记下来。
- **效应量与其区间一起抄**，只抄点估计会让后续综合无法进行。
- **抄不到就留空并标注**，不要用相近研究的值填。
- 全文拿不到的文献单独列出，说明尝试过的途径（见 `pdf-explore` 与开放获取抓取链）。

偏倚评估选与设计匹配的工具：RCT 用 Cochrane RoB 2，观察性研究用 ROBINS-I 或
Newcastle-Ottawa，诊断准确性用 QUADAS-2。选哪个要写明。

## 第 6 步：证据分级

单篇研究的质量与整体证据体的强度是两件事。整体强度用 GRADE 的五个降级维度：

| 维度 | 问什么 |
| --- | --- |
| 偏倚风险 | 各研究的设计与执行有多可靠 |
| 不一致性 | 各研究结果方向与大小是否一致 |
| 间接性 | 人群/干预/结局与你的问题差多远 |
| 不精确性 | 区间是否宽到跨越决策阈值 |
| 发表偏倚 | 小样本阳性结果是否过多（漏斗图/注册试验对照） |

结论落成四档：高 / 中 / 低 / 极低。**四档必须落在具体结局上**，不是给整篇综述打一个分——
同一个综述里「CPAP 改善日间嗜睡」可能是高质量证据，而「CPAP 改善认知」是低质量证据。

## 第 7 步：综合成文

- **按主题组织，不按文献罗列。** 「Smith 发现 X，Jones 发现 Y」是文献清单不是综述。
  综述要说「关于 X 有两类互相矛盾的结果，分歧可能来自测量方式的差异（研究 A、B 用 …，
  研究 C 用 …）」。
- **矛盾结果要正面处理**，给出可能的解释（人群、剂量、随访长度、测量工具、样本量）。
  把矛盾扫掉是综述里最常见的不诚实。
- **明确写出研究空白**，并说明为什么它是空白（没人做？做了但方法不足？）。
- **每一句有事实内容的话都要有引用**，且引用来自抽取表里的记录。
- 写完过一遍 `citation-verify`：核对每条引用真实存在、作者年份正确、且**确实支持**
  那句话。第三点最容易出问题——引用一篇真实存在但并不支持该论断的文献，是比编造引用
  更难被发现的错误。

## 编排建议

文献量大时用 `delegate` 并行：把「筛选」与「抽取」按文献分批派给子 agent，每批带上
纳入排除标准与抽取模板。子 agent 之间不共享状态，因此**标准必须完整写在任务描述里**，
不能依赖上下文。汇总回来后由主 agent 做一致性检查（同一字段的填法是否统一）。

宣称完成前跑 `check_findings`——审查者会检查引用与证据的对应关系。

## 验证清单

- [ ] 综述类型已确认（背景/系统/范围），系统综述已转 `systematic-review-prisma`
- [ ] 概念拆解含同义词、缩写、旧称、MeSH
- [ ] ≥2 个来源，每次检索的来源/检索式/日期/命中数都记录了
- [ ] 做了引文前向与后向追踪
- [ ] 去重规则记录了；预印本与正式版已合并
- [ ] 纳入排除标准在筛选**之前**定好并记录
- [ ] 每篇排除都有原因；单人筛选已如实说明
- [ ] 抽取表每个数据点都有 `quote` 与位置
- [ ] 数字来自正文而非摘要；摘要与正文不一致处已记录
- [ ] 偏倚评估工具与设计匹配且写明
- [ ] GRADE 分级按**每个结局**给出
- [ ] 矛盾结果正面处理，未被抹平
- [ ] 全文过了 `citation-verify`

## 存成制品

存：检索日志、原始命中记录、去重后库、筛选决策表（含排除原因）、抽取表、偏倚评估表、
GRADE 汇总表、参考文献导出（BibTeX / CSL-JSON）。

**筛选决策表与抽取表是这项工作的实体**。综述正文只是它们的一次叙述，而这两张表才是
可核对、可更新、可被别人复用的东西。下次要更新综述时，重跑检索并与旧表比对即可，
不必从头再来。
