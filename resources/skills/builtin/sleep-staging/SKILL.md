# 睡眠分期

## AASM 判读要点

30 秒一个 epoch，按占该 epoch **一半以上**的判据定级。五级：W、N1、N2、N3、R
（R&K 的 S3/S4 在 AASM 里合并为 N3；处理旧数据集时要显式做这个合并，别当成两级）。

- **W**：α 节律（8-13 Hz）占后头部导联 50% 以上，或有眨眼、快速眼动加高肌张力。
- **N1**：α 减少到 50% 以下，出现低幅混合频率活动；可有顶尖波、慢眼动。
- **N2**：出现 **K 复合波** 或 **纺锤波**（11-16 Hz，≥0.5 s）。规则关键点：一个 epoch
  只要在后半段出现纺锤波，**下一个** epoch 也算 N2（除非有觉醒）。
- **N3**：δ 波（0.5-2 Hz，峰峰值 >75 µV）占 20% 以上。注意阈值是 **20% 不是 50%**，
  这是最常被记错的一条。
- **R**：低幅混合频率 + **肌张力低下** + 快速眼动。肌张力是必要条件——没有 EMG 通道时
  R 与 N1 无法可靠区分，这个限制必须在方法里写明。

## 自动分期（yasa）

```python
import yasa
sls = yasa.SleepStaging(raw, eeg_name='C4-M1', eog_name='E1-M2', emg_name='EMG1-EMG2')
hypno = sls.predict()                # 每 30 s 一个标签
proba = sls.predict_proba()          # 各级后验概率
```

三条使用纪律：

1. **必须报告置信度分布。** `proba.max(axis=1)` 的中位数低于 0.7 时结果不可直接用于
   结论。把置信度作为一列存进制品，让审稿人能看到。
2. **通道名要传对。** yasa 按传入的通道做特征提取，传错通道不会报错，只会给出一份
   看起来正常的错分期。
3. **自动分期不是人工分期。** 论文里要写「使用 YASA v{版本} 自动分期」而不是「分期由
   技师完成」。与人工分期的一致性（Cohen's κ）在公开数据集上大致 0.75-0.80，
   逐级来看 N1 最差（κ 常低于 0.5）。

## 睡眠指标

```python
stats = yasa.sleep_statistics(hypno, sf_hyp=1/30)
```

指标定义容易被搞混，写进论文前核对：

- **TIB**（在床时间）：关灯到开灯。
- **TST**（总睡眠时间）：所有非 W 的 epoch 时长之和。
- **SE**（睡眠效率）= TST / TIB × 100。分母是 TIB 不是记录时长。
- **SOL**（入睡潜伏期）：关灯到**第一个**非 W epoch。有的定义要求连续三个 epoch，
  用哪个都行但必须写明。
- **WASO**：入睡后觉醒时间，不含入睡前。
- **各期占比**：分母习惯上是 TST 而不是 TIB。用 TIB 会让所有比例系统性偏低，
  与文献不可比。

## 分期图

```python
yasa.plot_hypnogram(hypno)
```

纵轴顺序按惯例自上而下 W、R、N1、N2、N3（R 紧邻 W）。REM 段常用加粗或变色标出。
横轴用**时钟时间**而不是 epoch 序号——审稿人要看的是「REM 集中在后半夜吗」。

## 常见错误

- **把自动分期当金标准做效度研究。** 要评估某个方法时，参照必须是人工分期，
  否则得到的是「两个自动方法有多像」。
- **忽略首夜效应。** 第一夜的 REM 潜伏期普遍延长、睡眠效率偏低。多夜设计要么弃第一夜，
  要么把夜次作为随机效应放进模型（见 `mixed-effects-models`）。
- **在 epoch 级数据上做逐 epoch 的独立性检验。** 相邻 epoch 高度相关，把 900 个 epoch
  当 900 个独立样本会让 p 值小得毫无意义。分析单位是**被试**或**夜**。
- **分期长度不一致就直接比较。** 有的数据集用 20 s 或 60 s epoch，指标不可直接比。
