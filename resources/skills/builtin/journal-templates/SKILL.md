# 期刊格式与投稿要求

## 第一条：以官方页面为准

**不要凭记忆填写期刊的字数限制、引用样式或图表数量上限。** 这些要求经常修改，
而记错的后果是格式退回（desk reject 的常见原因，且不进入审稿流程）。

正确做法：让用户提供目标期刊的作者指南页面或 PDF，逐条核对。拿不到时明确说
「以下按 {期刊} 的一般惯例给出，投稿前请核对官方作者指南」，不要给出确定的数字。

## 必须逐条核对的项目

抄成清单，逐项填写实际要求：

```
期刊：____________________  核对日期：__________  指南来源 URL：__________

□ 稿件类型（Original Article / Brief Report / …）及其各自的限制
□ 摘要：结构化还是非结构化？字数上限？
□ 正文字数上限（含不含摘要、参考文献、图注？）
□ 参考文献数量上限
□ 图表数量上限（超出的放补充材料）
□ 引用样式（Vancouver 编号 / APA 作者-年份 / 期刊自有）
□ 参考文献里期刊名用缩写还是全称
□ 行距与行号（多数要求双倍行距 + 连续行号）
□ 页码与页眉
□ 是否双盲送审
□ 图的格式与分辨率、是否需要单独文件
□ 结构化声明：伦理、知情同意、利益冲突、资助、作者贡献、数据可得性
□ 是否需要 Highlights / Graphical Abstract / Key Points
□ 报告规范：CONSORT（RCT）/ PRISMA（综述）/ STROBE（观察性）/ ARRIVE（动物）
□ 预注册号填在哪里
□ 字符集与语言变体（American vs British English）
```

**报告规范清单常常是必交项**，而且要标注每一条在稿件中的页码。这一步不能留到最后
——CONSORT 里的某些条目（如随机化实施细节）如果一开始没写，补的时候可能已经想不起来。

## 引用样式

| 样式 | 正文 | 参考文献列表 |
|---|---|---|
| Vancouver（多数医学期刊） | 上标或方括号数字，按首次出现顺序 | 编号，作者最多 6 位后加 et al. |
| APA 7 | (Smith & Lee, 2019) | 按作者姓字母序，最多 20 位作者 |
| Nature 风格 | 上标数字 | 编号，期刊名缩写无点 |

用 CSL（Citation Style Language）自动化，不要手工排版参考文献：

```python
# 项目里的参考文献以 CSL-JSON 存储，用 pandoc + CSL 样式渲染
# pandoc manuscript.md --citeproc --csl=vancouver.csl --bibliography=refs.json -o out.docx
```

CSL 样式文件可从 Zotero 样式库获取（数千种期刊样式）。手工排参考文献在转投时
要全部重做，且极易出错。

## 双盲送审

需要**两份稿件**：完整版与匿名版。匿名版要移除：

- 标题页的作者、单位、通讯信息、ORCID。
- 致谢（常含个人姓名与单位）。
- 资助信息（基金号可定位到单位）。
- 伦理批号里的机构名（改成「作者所在机构伦理委员会」）。
- 数据可得性声明里指向实验室仓库的链接（改为「审稿期间可按要求提供」）。
- 文件元数据里的作者字段（Word 的文档属性、PDF 的 Author）。

**自引的处理**：不要删掉自引（那会让文献综述不完整），改成第三人称表述
（把「我们此前发现」改成「Smith 等此前发现」）。彻底匿名往往做不到——
方法与数据集的独特性本身就能暴露身份。工具能处理结构化字段，
但**对写作风格、方法独特性、致谢里的隐式线索不作保证**，这一点要明确告知用户。

## 投稿包清单

```
□ Cover letter（见 cover-letter 技能）
□ 稿件正文（含或不含图，按要求）
□ 匿名版（若双盲）
□ 标题页（若与正文分开）
□ 图文件（每张单独，按编号命名）
□ 表格（正文内或单独文件）
□ 补充材料
□ 报告规范清单（CONSORT/PRISMA/STROBE），带页码
□ 伦理批件（部分期刊要求）
□ 版权/作者声明表
□ 推荐审稿人（如要求；注意回避规则）
□ Highlights / Graphical Abstract（如要求）
```

## 转投

被拒后换期刊时的最小改动集：

1. 引用样式（换 CSL 重渲染）。
2. 字数与图表数（按新上限裁）。
3. 摘要结构（结构化 ↔ 非结构化）。
4. Cover letter 重写（必须针对新期刊，不能只改刊名）。
5. **删掉上一家的稿件编号与审稿意见相关内容**——这类残留很常见且很显眼。

若上一家给过审稿意见，考虑主动附上「上一轮意见与我们的修改说明」。
部分期刊接受这种转投并能加快流程。

## 编译

用 `manuscript-compiler`（平台功能）把 Markdown 源 + CSL-JSON 参考文献编译成目标格式。
源文件保持单一，格式差异由样式文件承担——把格式硬编码进正文，转投时要全部重做。
