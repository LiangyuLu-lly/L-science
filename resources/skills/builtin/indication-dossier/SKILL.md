# 适应症证据档案

## 这份档案要回答什么

一个靶点-适应症组合值不值得投入。产出不是一段叙述，而是**一份结构化档案 + 一个明确的
证据强度判断 + 一份「还缺什么证据」的清单**。

先问清三件事（不清楚就用 `ask_user`）：

1. **靶点与适应症分别是什么。** 「治疗炎症」不是适应症，「中重度活动性克罗恩病」才是。
2. **方向。** 要激动还是抑制？降解还是阻断？这决定后面几乎所有证据的解读方向。
3. **用途。** 内部立项讨论、投资尽调、还是监管前沟通？详细程度差别很大。

## 七个板块

每个板块都要产出**表格**而不只是文字，且每一行带 `source` 与 `retrieved_at`。

### 1. 人类遗传学证据（权重最高）

这是所有证据里预测价值最高的一类：有人类遗传学支持的靶点在临床阶段的成功率显著更高。
要查的东西：

| 证据类型 | 查哪 | 怎么解读 |
| --- | --- | --- |
| 罕见变异-疾病关联 | ClinVar、Open Targets Genetics | 功能缺失变异导致疾病 ⇒ 支持激动/替代；获得功能导致疾病 ⇒ 支持抑制 |
| 常见变异 GWAS | GWAS Catalog、Open Targets | 看效应方向与最近基因的证据链是否可靠（最近基因常常不是效应基因） |
| eQTL / 共定位 | eQTL Catalogue、GTEx | 关联信号是否与该基因的表达调控共定位 |
| 保护性变异 | gnomAD + 文献 | **最强的一类**：天然功能缺失且健康（甚至受保护）⇒ 抑制该靶点安全性好 |
| 孟德尔随机化 | 文献 | 注意工具变量假设是否成立 |
| 约束性指标 | gnomAD 的 pLI / LOEUF | 高约束（pLI≈1）说明该基因不容忍功能缺失 ⇒ 抑制可能有安全风险 |

**方向一致性是这一节的核心判据**。遗传学证据支持的方向与你的干预方向相反时（比如
GWAS 提示功能缺失致病，而你要做抑制剂），这是一个严重的红旗，必须显式写出来，
不能因为「关联显著」就当成支持。

保护性功能缺失变异要特别查：它同时回答了有效性与安全性两个问题，是最有价值的单条证据。

### 2. 表达与定位

- 靶点在**病变组织/细胞类型**里表达吗（Human Protein Atlas、GTEx、单细胞图谱）
- 在**关键正常组织**里表达吗（心、肝、肾、脑、造血）——这是脱靶毒性的第一层预判
- 亚细胞定位是否与拟用模态相容：胞外/膜蛋白可做抗体；胞内需小分子或降解剂；
  分泌蛋白可做诱饵受体

单细胞层面的表达比 bulk 更有用（bulk 会把稀有细胞类型的高表达平均掉）。有数据时用
`scvi-tools` / `scgpt` 相关流程做定位分析。

### 3. 通路与机制

- 靶点在通路里的位置：上游节点效应大但脱靶风险高，下游节点更专一但可能被旁路绕过
- 已知冗余与代偿：同家族成员能否补偿？敲除后是否有代偿性上调
- 模型证据：小鼠敲除表型（IMPC/MGI）、条件敲除、类器官、患者来源细胞
- **物种差异**：小鼠表型与人类的相关性要单独评估。靶点在小鼠与人类的表达谱、
  家族成员数量不同是很常见的，而这类差异会让动物模型的阴性或阳性结果都不可外推

### 4. 可成药性

- 已有配体与化学起点（ChEMBL、BindingDB、PDB 里的 holo 结构）
- 结构可用性：有实验结构吗？没有的话预测结构够不够做设计（见 `alphafold2`、`boltz-2`）
- 口袋评估：有明确的小分子口袋吗？只有蛋白-蛋白界面吗？
- 模态匹配：小分子 / 抗体 / ASO-siRNA / 降解剂 / 细胞疗法 / 基因疗法各自的门槛
- 同家族选择性挑战：家族成员活性位点高度保守时，选择性是主要技术风险

### 5. 竞争格局与临床先例

```python
# 同靶点在研与已上市药物、各自适应症与阶段
trials = pd.DataFrame(columns=[
    'nct_id', 'title', 'phase', 'status', 'sponsor', 'intervention',
    'target', 'indication', 'n_enrolled', 'primary_endpoint',
    'start_date', 'completion_date', 'results_posted', 'source', 'retrieved_at',
])
```

要点：

- **失败的试验比成功的更有信息量。** 同靶点在相关适应症上失败过，必须找出失败原因
  （无效？毒性？入组？终点选择？），并说明你的方案为什么不会重复它。
- **注册但无结果的试验**要单独列出。它们往往是阴性结果，是发表偏倚的直接证据。
- 记录终点设计与入组标准——它们是后续临床方案的现成参照。

### 6. 安全信号

- 靶点的人类功能缺失表型（见第 1 节的保护性变异，反过来看）
- 关键正常组织表达（第 2 节）对应的器官毒性预期
- 同靶点/同通路药物的已知不良反应（openFDA 不良事件、说明书黑框警告）
- 同家族脱靶预期
- 妊娠/发育相关：靶点在发育中的作用

**安全信号不足不等于安全。** 新靶点没有已知不良反应通常只说明没人试过。要写「缺乏
人类安全数据」而不是「安全性良好」。

### 7. 生物标志物与开发路径

- 靶点参与度标志物（能证明药物打到了靶）
- 患者富集标志物（哪些患者更可能响应）
- 药效标志物与临床终点的关系
- 监管路径：有无既有的可接受终点？是否可能走加速审批？

## 证据强度判断

给每个板块一个强度评级，然后给一个整体判断。**不要给一个综合数字分**——把遗传学证据与
竞争格局加权成一个「7.4 分」会掩盖掉决策真正依赖的信息。

```python
verdict = pd.DataFrame([
    {'domain': '人类遗传学', 'strength': '强', 'direction': '与拟用方向一致',
     'key_evidence': 'LoF 保护性变异，n=...；来源与日期见证据表'},
    {'domain': '可成药性',   'strength': '中', 'direction': '—',
     'key_evidence': '有 holo 结构，但家族保守性高，选择性是主要风险'},
])
```

强度用四档（强/中/弱/缺失），并对每一档写出**判据**而不只是结论。

最后必须有一节 **「缺什么证据 / 下一步做什么能最快降低不确定性」**。这是档案对决策
真正有用的部分：列出 2-4 项具体实验或分析，每项说明它能排除哪个风险。

## 三条不能违反的纪律

1. **每条论断绑定数据源与查询日期。** 数据库在更新，一条今天成立的判断半年后可能不成立。
   没有 `retrieved_at` 的证据表在半年后无法判断是否需要重查。
2. **推测必须显式标注。** 档案里会有基于机制的合理推断，这是正常的；但它必须与
   有直接证据的论断在版式上区分开。混在一起是这类文档最常见也最危险的问题——读者会
   把推测当证据去做决策。用一列 `evidence_type ∈ {direct, inferred, speculative}`。
3. **不给医疗或投资建议。** 这份档案是证据汇编与技术评估，不是「应该投多少钱」或
   「这个药能治好病」。结论落在证据强度与风险清单上。

## 编排建议

七个板块之间依赖弱，适合并行。用 `delegate` 每个板块派一个子 agent，任务描述里带上：
靶点、适应症、干预方向、该板块要查的数据源清单、输出表的列定义。

子 agent 看不到彼此，因此**列定义必须完整写在任务里**，否则汇总时各表格式不一致。
汇总回来后主 agent 做三件事：跨板块一致性检查（尤其第 1 节的方向与第 6 节的安全预期
是否自相矛盾）、去重、强度评级。

宣称完成前跑 `check_findings`。

## 存成制品

存：七张板块证据表、强度评级表、缺口与下一步清单、全部检索的查询日志（含日期）、
参考文献导出。

**证据表 + 查询日志才是可复用的资产**。半年后要更新这份档案，重跑查询并 diff 即可；
只留一份 PDF 报告的话，下次得从头做一遍。
