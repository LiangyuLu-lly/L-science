# 论文结构

## 各部分的功能与边界

| 部分 | 回答的问题 | 越界的表现 |
|---|---|---|
| 标题 | 研究了什么 | 写成结论；用问号；堆缩写 |
| 摘要 | 全文的可独立阅读版本 | 出现正文没有的数据；只说「结果将被讨论」 |
| 引言 | 为什么值得做 | 写成小型综述；把结论提前说完 |
| 方法 | 别人怎么重做 | 缺参数；引用「如前所述」但前文也没写 |
| 结果 | 观察到了什么 | **解释原因**；引用他人文献；用「显著改善」这类评价词 |
| 讨论 | 这意味着什么 | 出现新数据；把探索性发现说成确认性 |
| 局限 | 结论的边界在哪 | 写成套话（「样本量较小」但不说影响什么） |

**结果里不解释、讨论里不出新数据**，这两条是审稿人最常提的结构性问题。

## 标题

- 陈述研究对象与设计，不下结论。
  - 差：`CBT-I 显著改善老年失眠患者的睡眠质量`
  - 好：`认知行为治疗对老年原发性失眠患者多导睡眠图指标的影响：随机对照试验`
- 设计写进副标题（`：随机对照试验` / `：横断面研究` / `：系统综述与元分析`）。
  很多期刊硬性要求，且它让读者立刻知道证据强度。
- 缩写只用领域内绝对通行的（PSG、EEG、REM）。
- 长度按目标期刊要求，多数在 15-20 词以内。

## 摘要

结构化摘要（多数医学期刊）：Background / Methods / Results / Conclusions。

三条硬要求：

1. **给具体数值。** 「组间差异显著」没有信息量，「TST 增加 34 min（95% CI [18, 50]，
   p<.001）」才有。摘要里的每个数都必须在正文中出现且完全一致。
2. **样本量与设计在 Methods 第一句。**
3. **结论不超出数据。** 单次横断面研究的结论不能是因果表述。

摘要是被读得最多的部分——很多读者只读它。它必须能独立成立。

## 引言

三段漏斗：

1. **领域背景**：这个问题为什么重要（2-4 句，不要写成综述）。
2. **具体空白**：已知什么、缺什么。要具体到可检验：
   「已有研究多在青年样本上进行，老年人群中慢波—纺锤波耦合是否同样预测记忆巩固尚不清楚」。
3. **本研究做什么**：目的与假设。假设要**方向明确**（不是「我们探索了两者的关系」，
   而是「我们假设耦合强度与记忆保持率正相关」）。

引言不给结论。最后一句说「我们做了什么」，不说「我们发现了什么」。

## 方法

判据只有一个：**读完能重做吗**。逐项检查：

- 设计与预注册号；伦理批号与知情同意。
- 参与者：招募来源、纳入排除、样本量估算（见 `power-analysis`）。
- 设备与采集：型号、采样率、电极位置与参考、滤波设置。
- 处理：软件与**版本号**、每一步的具体参数（见 `eeg-preprocess`）。
- 结局指标的**操作性定义**（TST 怎么算，见 `sleep-staging`）。
- 统计：模型公式、随机效应结构、多重比较校正方法、显著性水平、软件版本。
- 数据与代码可得性（见 `data-availability-statement`）。

「按标准流程处理」不是方法描述。「使用 MNE-Python 1.12.1 做 0.3-35 Hz 带通
（FIR，firwin），参考双侧乳突」才是。

## 结果

- 按研究问题组织，不按分析时间顺序。
- 先给描述统计（表 1：人口学与基线），再给主要结局，再给次要结局。
- 每个推断都带**效应量与置信区间**，不只是 p 值。
- 图表自足：读者只看图表和标题应该能理解，不必回正文找。
- **不解释**。「N3 时长减少 18 min（p=.002）」而不是「由于年龄相关的稳态下降，
  N3 时长减少」。

## 讨论

1. **主要发现**（1 段，不重复结果的数字堆砌，说它意味着什么）。
2. **与既有文献的关系**：一致的、不一致的都要说。不一致时给出可能原因
   （人群、方法、样本量）——只报告一致的文献是选择性引用。
3. **机制解释**：明确标注为推测。
4. **局限**：见下。
5. **结论**：一到两句，与数据强度匹配。

## 局限段的写法

套话没有价值。每条局限要写清**它影响什么结论、影响方向如何**：

- 差：「样本量较小。」
- 好：「样本量为每组 22 人，仅能检出 d≥0.86 的效应；因此本研究不能排除中等大小的
  组间差异（次要结局的置信区间上界达 21 min）。」

- 差：「使用了自动分期。」
- 好：「分期由 YASA 自动完成，与人工分期的一致性在 N1 上较低（文献报告 κ≈0.45）。
  由于本研究的主要结局是 N3 时长（κ≈0.80），预计影响有限，但 N1 相关的次要结果
  应谨慎解读。」

## 投稿前自查

- 摘要里的每个数与正文一致？
- 每张图表在正文中都被引用且编号连续？
- 每条引文都经核实（见 `citation-verify`）？
- 每个 p 值都有对应的效应量？
- 多重比较校正写明了方法与家族？
- 软件版本号全部给出？
- 图表能在灰度下辨认（见 `figure-standards`）？
